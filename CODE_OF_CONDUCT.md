# Code of Conduct / 行動規範

日本語: 参加者を尊重し、嫌がらせ、差別、脅迫、個人情報の公開を行わないでください。安全上の懸念は公開スレッドではなく、配布元が示す非公開窓口へ連絡してください。

English: Treat participants with respect. Harassment, discrimination, threats, and publication of personal information are not acceptable. Report safety concerns through the distributor's private channel, not a public thread.

Maintainers may remove content or participation that violates this standard.
