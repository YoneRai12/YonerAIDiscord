# Contributing / 貢献

日本語: 変更は最小範囲にし、危険な機能を既定で有効化しないでください。PRには目的、テスト、公開境界への影響、live未検証の範囲を記載してください。秘密情報、内部ID、私的なパス、運用ログは含めません。

English: Keep changes narrow and never enable risky features by default. A pull request must state its intent, tests, public-boundary impact, and what remains not live-verified. Do not include secrets, internal IDs, private paths, or operational logs.

Contributions are accepted only under the repository's source-available non-commercial terms.
