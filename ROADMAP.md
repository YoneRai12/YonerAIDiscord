# Roadmap / ロードマップ

日本語: ロードマップは方向性であり、約束、納期、またはlive提供の保証ではありません。安全性、権限境界、所有者承認を満たした項目だけが実装候補になります。

English: This roadmap communicates direction only; it is not a promise, schedule, or guarantee of a live offering. Only work that satisfies safety, authority boundaries, and owner approval may become implementation work.

- Keep externally impactful features OFF by default.
- Improve offline tests and public documentation.
- Require explicit owner approval before any live integration or mutation.
