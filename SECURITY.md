# Security / セキュリティ

日本語: 脆弱性、認証情報の露出、権限昇格、予期しない外部操作は公開Issueに投稿しないでください。GitHubのprivate vulnerability reporting（`https://github.com/YoneRai12/YonerAIDiscord/security/advisories/new`）へ、再現に必要な最小限の情報だけを送ってください。token、cookie、個人情報、実サーバーID、private path、live logは除外してください。

English: Do not file public issues for vulnerabilities, credential exposure, privilege escalation, or unintended external actions. Use GitHub private vulnerability reporting at `https://github.com/YoneRai12/YonerAIDiscord/security/advisories/new` and send only the minimum reproducible information. Exclude tokens, cookies, personal data, real server identifiers, private paths, and live logs.

No response-time or bounty commitment is made by this template. Do not test against systems you do not own or control.
