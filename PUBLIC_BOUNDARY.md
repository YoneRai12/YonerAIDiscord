# Public Boundary / 公開境界

日本語: 公開エクスポートは、公開用に承認されたソース、依存関係通知、一般的な文書だけを含めます。秘密情報、認証情報、token、cookie、private path、実ID、運用ログ、live構成、実環境の状態は含めません。

English: A public export contains only approved public source, dependency notices, and general documentation. It excludes secrets, credentials, tokens, cookies, private paths, real identifiers, operational logs, live configuration, and real-environment state.

Public documentation must not infer readiness from source presence. Offline verification, configuration, and live verification are separate states.
